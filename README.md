# Markdown

# Vad är Markdown?
Markdown är ett så kallat märkspråk som används för att strukturera och formatera text. Det innebär att man kan skapa exempelvis rubriker, punktlistor, tabeller och fetstil utan att behöva använda en massa avancerade verktyg.

Det som gör Markdown användbart är att man skriver med vanliga tecken på tangentbordet, och de tecknen bestämmer sedan hur texten ska visas

## Guide på Markdown
*  Rubrik 1 (#)
*  Underrubrik (##/###)
*  Bild = ! (option 8 = [ ]) ()
  För att lägga in en bild använder man först ett utropstecken, sedan hakparenteser och till sist vanliga parenteser.
*  Punktlista ( shift ' = * )
  För att skapa en punklista skriver man en stjärna förljt av ett mellanslag framför varje punkt.
*  Kursivtext ( shift ' = *Kursivtext* )
  För att ska kursivstil sätter man en stjärna före och efter texten. 
*  Fettext ( shift ' ' = *Fettext** )
  För att ska fetstill sätter man två stjärnor före och efter texten.
*  Tabel ( option 7 = | | )
 I Markdown kan man skapa tabeller med hjälp av lodräta streck, alltså |, och bindestreck.
