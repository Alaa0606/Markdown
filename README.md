# Markdown

# Vad är Markdown?
Markdown är ett snabbt och lätt sätt att formatera text med hjälp av vanliga tecken, till exemple #,* och -.

# Vad används de till?
Man kan använda Markdown för att skapa, Rubriker, underrubriker, text, fetstil, kursiv ock tabeller utan att behöva använda World eller HTML:

## Guide på Markdown
*  Rubrik 1 (#)
*  Underrubrik (##/###)
*  Bild = ! (option 8 = [ ]) ()
  För att lägga in en bild använder man först ett utropstecken, sedan hakparenteser och till sist vanliga parenteser.*  Punktlista ( shift ' = * )
  För att skapa en punklista skriver man en stjärna förljt av ett mellanslag framför varje punkt.
*  Kursivtext ( shift ' = *Kursivtext* )
  För att ska kursivstil sätter man en stjärna före och efter texten. 
*  Fettext ( shift ' ' = *Fettext** )
  För att ska fetstill sätter man två stjärnor före och efter texten.
*  Tabel ( option 7 = | | )
 I Markdown kan man skapa tabeller med hjälp av lodräta streck, alltså |, och bindestreck.
